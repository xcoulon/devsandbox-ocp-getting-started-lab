= Step 2.1: Switch to your lab project
:source-highlighter: highlightjs

[%collapsible]
.Using the Terminal (CLI)
====
[source,role="execute",subs="attributes+"]
----
oc project {user}-lab
----

[%collapsible]
.Expected output
=====
[subs="attributes+"]
----
Now using project "{user}-lab" on server "{openshift_api_url}".
----
=====
====

[%collapsible]
.Using the Web Console
====
In the top-left corner of the navigation panel, click the current project name to open the
project selector. Select *`{user}-lab`* from the list.
