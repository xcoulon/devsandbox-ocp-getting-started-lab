= Step 3.1: Clean up the manual deployments
:source-highlighter: highlightjs

First, remove the resources you created manually in Section 2. Use the Terminal for this step --
deleting multiple resource types is much faster from the CLI.

[source,role="execute",subs="attributes+"]
----
oc delete all --selector app=datasphere-ui -n {lab-namespace}
oc delete all --selector app=datasphere-api -n {lab-namespace}
----

[%collapsible]
.Expected output
====
[subs="attributes+"]
----
service "datasphere-ui" deleted from {lab-namespace} namespace
deployment.apps "datasphere-ui" deleted from {lab-namespace} namespace
imagestream.image.openshift.io "datasphere-ui" deleted from {lab-namespace} namespace
route.route.openshift.io "datasphere-ui" deleted from {lab-namespace} namespace
service "datasphere-api" deleted from {lab-namespace} namespace
deployment.apps "datasphere-api" deleted from {lab-namespace} namespace
buildconfig.build.openshift.io "datasphere-api" deleted from {lab-namespace} namespace
imagestream.image.openshift.io "datasphere-api" deleted from {lab-namespace} namespace
----
====

Verify the project is clean:

[source,role="execute",subs="attributes+"]
----
oc get all -n {lab-namespace}
----

[%collapsible]
.Expected output
====
[subs="attributes+"]
----
No resources found in {lab-namespace} namespace.
----
====
