= Get connected
:source-highlighter: highlightjs

Each step in this lab includes both a *Terminal (CLI)* and a *Web Console* option.
Use whichever you prefer -- both achieve the same result.

[%collapsible]
.Using Terminal CLI
====

Expand the top-right menu showing your username, then click "Copy login command".
Click on "Display token" then copy the `oc login` command.

Open a terminal session on your machine and paste the `oc login` command


[source,role="execute",subs="attributes+"]
----
oc login --token=... --server=...
----

Note: If `oc` is not already installed on your machine, you can download it directly from the OpenShift console: 
click the *?* icon in the top-right corner, select *Command Line Tools*, and download the version of `oc` 
that matches your operating system.
