= Step 2.5: (Optional) Browse the source code in Gitea
:source-highlighter: highlightjs

Your lab environment includes a personal Gitea instance with the DataSphere API source code
already loaded. 

In the left navigation, expand *console:qs-nav-networking[Networking]*, select *resource:route.openshift.io/v1/Route[Routes]*, then choose *`{gitea-namespace}`* in the project selector.
Click on the location link of the *gitea* route to access Gitea

If you see *Sign In* and *Register* buttons, you are not logged in yet. Click *Sign In* and
use your lab credentials (`{gitea-admin-username}` / `{gitea-admin-password}`). After logging in, your repositories are
listed on the dashboard -- click *datasphere-api*.

You can also open the repository directly in a new tab:
link:https://{gitea-rootUrl}/{gitea-admin-username}/datasphere-api[{gitea-rootUrl}/{gitea-admin-username}/datasphere-api, window=_blank]

You can skip this step -- the next command pulls the source directly from Gitea.
